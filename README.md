## 👋 About me

I started programming in **2018**, and the reason was simple: I wanted to make cheats for Roblox. That got me curious about how games actually work on the inside, and the curiosity never went away.

Since then I've picked up more languages and moved on to other games. Today I make cheats for several of them, and I also work on the other side, building anticheats.

I speak **Portuguese** and **English**.
